# GM не спит

Статический лендинг канала. Не требует Higgsfield, сборки или серверной инфраструктуры.

## Локальный запуск

Откройте `index.html` в браузере или используйте любой статический сервер.

## Deploy

Импортируйте репозиторий в Vercel как **Other / Static**: build command и output directory не требуются.
